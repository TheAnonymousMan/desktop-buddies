# What's fullscreen? How the buddies tell a show from a game from a meeting.
#
# Each line under a [section] is one clue:
#   exe:   the program's file name                  exe: vlc.exe
#   path:  part of the folder the program lives in  path: steamapps
#   title: a word in the window's title             title: netflix
#   class: the window's kind (tools/fullscreen_check.py prints it)
# Matching ignores upper/lower case. Lines starting with # are ignored.
#
# Window titles are only checked against these words, right then and there.
# They are never saved, logged or sent anywhere.
#
# [present]  hide completely and silently (slideshows, meetings)
# [share]    hide completely whenever one of these windows is open anywhere,
#            fullscreen or not (screen sharing)
# [game]     the buddies sit and cheer you on
# [video]    the buddies sit down with popcorn and keep quiet
# Anything else fullscreen: they sit and watch from another screen.
